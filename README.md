## 🛰️ Research & Internship Project

**Technosignature Search at INAF – Sardinia Radio Telescope**  
Adaptation and validation on real SRT data of a multi-stage ML pipeline for technosignature detection, based on the method of Pardo et al. (AJ 2025). The pipeline combines a **density filter** (UMAP + KDE), a **frequency filter** (ensemble GMM with bagging), and an **ON/OFF similarity filter** in UMAP space. Original contributions include an NCC-max feature extractor (tolerant to frequency drifts) and a convolutional autoencoder extension optimized via Keras Tuner / Hyperband with 3-phase training and memory mapping for datasets > 32 GB.

🔗 Repository: [srt-anomaly-detection](https://github.com/DavideDeplano/srt-anomaly-detection)
